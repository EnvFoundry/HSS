# 定性与混合研究

选择分析取向：主题分析、扎根理论、民族志、叙事、案例或过程研究。说明研究问题、研究者位置与材料形成方式，再决定案例、受访者、观察场景和比较方式。

访谈由开放问题与追问路径组成。转录保存参与者、时间与位置。编码表包含概念定义、适用片段、相邻概念和分析备忘录。以新的材料比较修正编码，明确描述性编码与解释性类别的关系。

主题通过材料之间的联系和差异发展。记录支持主要解释的片段，也分析难以纳入的片段。过程研究先重建事件与行动，再说明机制如何连接这些过程。QCA 的条件集合与校准须与案例含义相符。

`coding` 汇总研究者提供的区间标注，返回片段、计数和共现表。`agreement` 用于需要固定分类一致性的任务；反思性主题分析等取向不要求统一使用该统计量。

混合方法明确先后关系、连接单位与整合位置。联合展示要解释两类结果如何相互补充、修正或产生新问题。
