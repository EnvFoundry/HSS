# 行为与现场实验

将研究问题写成操纵、比较、响应与时间的关系。明确随机分配单位、刺激、任务顺序、实施场景与主要结果。多人互动实验还需说明匹配、信息结构、报酬与重复互动。

先用少量试次检查刺激、按键、时序和数据导出，再开始正式采集。参与者身份、联系方式与研究分析表分开管理；按实际机构要求安排参与说明与相关手续。

`experiment` 生成 jsPsych 页面和刺激配置。浏览器时间记录受设备和运行环境影响，精确时序研究需选择相应设备与软件。软件模拟试次用于调试流程，不能作为参与者响应。

分析按分配结构组织。基线调整可提高精度，失访、依从和群体互动会改变需要回答的问题。完整保存试次字段与编码规则。

参考：<https://www.jspsych.org/>；<https://www.otree.org/>。
