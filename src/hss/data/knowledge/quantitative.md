# 统计分析与模型含义

明确一行数据的单位、总体范围、变量定义和数据形成过程。处理缺失、权重、分组与时间结构后，选择对应目标的统计量或模型。

线性关联以协变量集合和函数形式为条件。回归表同时呈现量级、单位和不确定性。聚类推断的独立单位是簇；层级模型与聚类标准误承担不同任务。

`summary` 提供均值、分位数及适用的区间；`distribution` 提供经验分布与非负变量上的不平等指标；`ols` 提供 HC3 或单向 CR1；`kaplan_meier` 处理独立右删失；`oaxaca` 按指定参考组分解均值差异。

这些程序有明确输入范围。复杂抽样使用 survey，多层模型使用 lme4，面板和固定效应使用 fixest 或 linearmodels。通过执行入口可使用上游完整 API。

参数解释应回到研究问题。描述、关联、因果与预测可以使用相似方程，但设计与结论含义不同。
