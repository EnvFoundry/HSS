# 因果设计与效果分析

明确处理对比、结果、总体、时间起点和目标效应。解释什么分配机制、制度规则或可比较变化使反事实有意义，再选择估计器。

随机实验区分分配与实际接受处理。条件调整说明处理前变量、重叠和潜在混杂。工具变量说明相关性、排除限制及目标群体；普通两阶段 Wald 区间不适合弱工具情形。

DID 区分两期与分批实施。多期问题使用组别时期效应及合适聚合；两期数据本身不能提供处理前动态。断点研究区分连续性框架与局部随机化。合成控制说明供体、处理前信息与政策开始时间。

中介研究同时涉及处理到中介及中介到结果的关系，单纯系数变化不能完成整个解释。网络干扰需定义暴露及直接、间接效应。

本地计算的具体范围见任务输出和方法条目。复杂设计可生成 R 分析脚本或使用连接后的软件完整接口。结果的解释取决于设计与数据，估计完成后回到原问题讨论。
