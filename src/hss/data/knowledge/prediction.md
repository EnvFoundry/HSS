# 预测、分类与模式发现

先定义预测对象、预测时点、可获得的信息与损失。按应用场景选择个体独立、群组、地域或时间划分。未来信息不能进入过去时点的特征。

预处理、特征选择与模型调整在训练部分完成。独立测试材料用于最终比较。报告与简单基线的差异、分组表现、校准以及实际错误的含义。

`predict` 支持连续或分类结果，`text_predict` 在训练文本拟合词表，`autoreg` 提供固定阶数的逐步时间预测。`conformal` 使用明确的三组划分产生边际预测区间。

聚类与主题分析用于发现模式。解释类别时联系具体对象和外部材料，说明选择参数或材料范围如何影响划分。预测特征的重要性不直接等于干预效果。
