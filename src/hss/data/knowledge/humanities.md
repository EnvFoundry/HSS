# 文本、意义与解释

从作品、文本、图像、制度表述或具体实践提出解释问题。说明材料边界及作品内部的结构，联系作者、受众、生产、传播与接受语境。

细读关注形式、叙述视角、修辞、节奏、图像安排和概念选择。记录足以让读者理解解释的原文位置；引文与释义分开。解释不同片段之间的联系，并讨论与主要解释不吻合的材料。

话语研究区分词语出现、表述方式、主体位置与制度实践。叙事研究区分故事时间和讲述时间。翻译比较区分语义、语用、语域和文化选择。法律研究明确法源、适用时间、事实情形及解释路径。

计算文本工具帮助检索、比较与聚合。频次、主题或相似度的研究含义，需要回到具体文本讨论。方法的完成形式可以是解释论述、概念重建或材料编排。
