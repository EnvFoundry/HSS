# 史料、时间与文本

明确材料形成时间、作者或机构、载体、保存位置、版本与研究使用的副本。区分事件发生时间、记录时间与后来的编辑时间。转录保留页码或段落标识，便于回到材料。

从具体问题决定史料范围。比较同一事件的不同记录、同一概念在不同场景中的用法，以及材料留下与未留下的原因。不要把今天的概念无说明地套到历史行动者身上。

文本比较使用 `collate` 输出原文与对应差异，再判断差异来自录入、版本、译法还是思想变化。`corpus` 可以读取 TEI，保留段落标识；复杂的手稿异文继续使用原始 XML 和专业编辑工具。

历史比较说明案例为什么可比、不同材料承担什么解释任务、时序与制度之间如何相互作用。数字统计用于发现模式，具体解释仍联系可定位的史料与语境。

参考：<https://tei-c.org/>；<https://iiif.io/>。
