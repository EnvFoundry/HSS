# 概念、解释与规范论证

概念分析从实际用法、典型实例和边界实例开始。区分定义、经验判断、理论假设和价值前提。对同名异义与异名同义分别建立联系。

理论构建说明主体、情境、行动逻辑、约束、互动与过程。推演哪些条件变化会改变结果，以及不同解释会产生什么不同观察。形式化适用于策略互动、反馈、均衡或相反力量难以通过文字理清的情形。将推导、数值求解和模拟发现分别说明。

规范研究明确价值立场、适用对象、冲突情形和实践后果。经验材料可以改变事实前提，规范结论还需要其价值论证。比较不同立场时，按各自最有说服力的形式重建其论证。

`argument_map` 接收明确提供的命题与支持、反对或依赖关系，生成可阅读的论证图。它整理论证结构；命题含义与推导是否成立，由具体分析完成。图中的节点使用短句，正文解释关键推导。
