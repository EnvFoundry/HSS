# 概念与测量

区分理论概念、操作定义、题项或指标以及实际字段。说明概念的维度、参照对象、时期和测量情境。代理指标应明确保留了哪个维度。

量表开发结合题项来源、内容覆盖、认知访谈与试测。因子模型或项目反应模型按理论及题项性质指定。跨时期、语言或群体比较时研究测量含义是否相同。

主成分用于低维表示；潜变量模型表达特定的测量结构。二者的研究含义分别解释。模型拟合、内部一致性和测量的实质含义各自回答不同问题。

使用 lavaan 时提供明确模型式、题项类型及估计器；使用 mirt 时提供题项响应与计分规则。输出参数、模型设定和支持解释所需的图表。

参考：<https://lavaan.ugent.be/>；<https://cran.r-project.org/package=mirt>。
