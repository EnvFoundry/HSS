# 文献与研究脉络

将研究问题拆为对象、概念、关系、制度与相邻学科术语。保留中英文表达，并从种子论文开展前向、后向引文追踪。使用 Crossref、OpenAlex、Zotero 或研究者提供的数据库导出；访问方式在资源目录中单独登记。

每篇关键研究记录问题、理论、材料、设计、分析方式、结论及对应原文位置。只有摘要时按摘要内容表达。用问题与解释的关系组织综述，比较研究之间的共识、分歧以及分歧可能来自的对象、时期、测量或设计变化。

避免用论文数量或更换地区来代替知识贡献。先说明已有研究回答了什么，再说明当前问题如何改变、扩展或重组这些认识。历史或思想研究也记录版本、译本、作者处境与文本形成时间。

`hss source search crossref --query ...` 返回书目记录。`bibliography` 操作把明确提供的条目放入项目 SQLite 文献库；数据库保存条目与阅读笔记，不自动下载全文。
