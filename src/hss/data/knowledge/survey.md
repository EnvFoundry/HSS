# 调查、抽样与问卷

先说明目标总体和抽样框。根据进入样本的方式区分概率样本、便利样本和自选样本。复杂设计记录分层、整群、入样概率、权重和相应分析单位。

问卷中的题目应对应清楚的概念。区分事实、态度、回忆和假设选择；注意参照时期、措辞、选项覆盖、跳转与顺序。认知访谈和试测用于理解受访者如何作答。

`questionnaire` 接收研究者提供的题目与选项，生成 JSON 描述和可读表格。LimeSurvey 等平台由连接配置提供。样本量取决于目标精度、效应规模、设计效应、组数与实际资源。

分析时保持权重、分层和抽样单位的含义。普通加权均值与复杂抽样总体区间需要不同的实现。R survey 用于明确提供调查设计的分析。

参考：<https://cran.r-project.org/package=survey>。
