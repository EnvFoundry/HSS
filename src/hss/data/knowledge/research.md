# 从问题进入研究

先说明希望增加什么认识，再决定需要哪些材料与操作。区分研究对象、观察单位、分析单位和结论适用范围。一个项目可同时承担描述、解释、因果、预测或规范任务，各任务写出自己的目标答案。

从用户已有内容出发，形成少量有实质区别的研究问题。比较它们的理论意义、可取得材料、工作量和可能改变的认识。问题清楚后，说明理论或概念、材料范围、研究设计、分析程序与成果形式之间的关系。

用 `hss context MODULE` 加载当前任务的方法；用 `hss methods QUERY` 查找细分方法。资料不足时先查目录、阅读样例或开展小规模试测。解释出现分歧时，明确哪项新观察、材料或推导会区分这些解释。

研究方案保留文字论述。可计算任务另写为 `study.json`，其中每个任务说明 `operation`、`data`、`variables` 及必要设置。概念分析和文本阐释以论证与材料组织为主，无须填写无关的统计字段。

与研究者讨论会实质改变目标或设计的选择。已明确的工作自主推进。完成一轮后形成有内容的结果，并指出直接关联的下一项研究工作。
