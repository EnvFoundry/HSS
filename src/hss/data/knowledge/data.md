# 数据与材料的组织

为每张表说明一行代表什么、主键、变量含义、单位与时间。区别零值、缺失、不适用和未记录。任何筛选、转换或聚合都应有清楚目的。

联结前说明双方粒度及一对一、一对多或多对多关系。匹配后的样本构成会影响可回答的问题。对象标识相似不表示来自不同来源的记录能直接相连。

数据目录、实际取得的数据与可以执行的分析分别记录。大型数据留在项目或数据平台，模块目录保存说明和连接入口。API 返回的当前记录不自动代表历史状态。

`table` 读取 CSV 并输出字段概要；DuckDB 和 Arrow 处理更大的表与联结。SQLite 可用于项目文献和材料索引。工具始终接受明确数据路径，不扫描用户所有目录。
