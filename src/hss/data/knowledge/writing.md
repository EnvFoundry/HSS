# 从研究形成文字

先写核心问题与本研究增加的认识，再组织理论、材料、方法、分析和讨论。人文学术文章可以按论证推进；实证文章可以按研究设计与结果推进。根据目标读者选择结构。

每一段发展一个明确观点，让下一句回应上一句留下的问题。解释变量、参数或引文如何支持当前论述。删除空泛评价、重复结论与与主线无关的流程文字。

区分已有研究、本次实际完成的分析和进一步设想。数字与图表来自实际产物，引用对应真实来源及具体位置。未开展的实验或访谈保留为后续研究。

研究者可以形成论文、专著章节、政策报告、数据说明或课程材料。通用模板和编译环境优先复用 SeedEnv Scientific Writing；Quarto 与 Pandoc 提供其他编排方式。
