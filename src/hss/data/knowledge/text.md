# 语料与文本计算

确定一篇文档、一个段落和一个分析单位分别代表什么。保存原文本及其来源；分词、规范化和特征构造生成派生表示。中文按研究任务选择词、字或短语，不默认使用英文分词规则。

`corpus` 将材料转为文档与片段，片段保留字符起止位置。`concordance` 用检索词返回上下文。`collate` 比较两个明确文本。PDF 的文本提取与扫描页识别是不同步骤；扫描页需要 OCR 工具与对应语言数据。

监督分类先确定标签含义及标注方式。特征、词表和超参数选择使用训练材料，最终比较使用独立材料。主题模型的主题数和词表改变可能产生不同划分，结合具体文档解释这些变化。

语言模型、嵌入模型与大型语料独立选择和准备。安装语言处理软件不包含下载全部语言模型。
